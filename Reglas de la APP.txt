Si una oportunidad de intraday o swing tiene una expectativa significativamente mejor que una oportunidad de scalping, el sistema debe poder considerarla.

La arquitectura debe permitir que en el futuro podamos añadir estrategias de diferentes horizontes temporales sin reconstruir todo el sistema.

3. FILOSOFÍA MUY IMPORTANTE: EXPLORACIÓN AL INICIO

Quiero modificar una parte fundamental de la filosofía del sistema.

NO quiero que el bot sea excesivamente conservador al principio.

Al inicio quiero que el sistema tenga una fase de exploración.

Es aceptable que cometa errores.

De hecho, quiero que pueda cometer errores controlados porque:

cada operación perdedora genera información que puede utilizar para mejorar el sistema.

No quiero exigir desde el primer día que cada operación tenga un confidence score extremadamente alto.

No quiero que un sistema demasiado restrictivo termine haciendo tan pocas operaciones que no tenga suficientes datos para aprender.

Por lo tanto, quiero implementar un sistema de:

EXPLORATION vs EXPLOITATION

Al principio:

Exploration weight = HIGH

Posteriormente:

Exploitation weight = INCREASED

A medida que acumula datos:





las estrategias que producen buenos resultados reciben mayor prioridad



las estrategias con mala expectancy reciben menor prioridad



las configuraciones consistentemente perdedoras se reducen o eliminan



las nuevas estrategias todavía pueden recibir oportunidades controladas de exploración



4. MENOS FILTROS AL INICIO

Quiero explícitamente que el sistema NO tenga demasiados filtros al principio.

No quiero algo como:

"Solamente operar si 15 indicadores están alineados."

Eso podría eliminar demasiadas oportunidades y dificultar el aprendizaje.

Al principio quiero un sistema con un entry threshold relativamente flexible, siempre que la operación:





tenga una lógica identificable



tenga un riesgo definido



tenga datos suficientes para analizarla



respete el Risk Manager

El objetivo inicial no es conseguir una tasa de acierto perfecta.

El objetivo inicial es:

generar suficientes datos de calidad para descubrir qué funciona.

13. POSITION SIZING

La idea inicial es utilizar operaciones pequeñas.

Por ejemplo:

€2–€3 por operación.

Existe una idea inicial de incrementar aproximadamente €1 el tamaño de las operaciones cuando el capital aumente €50.

€150 → €3–€4

€200 → €4–€5

etc.

Y reducir aproximadamente €1 cuando el capital retroceda €50.

€2–€3

Sin embargo:

NO quiero que implementes esta regla literalmente sin analizarla.

Quiero que investigues si existe una metodología superior.

Puedes considerar:

Si encuentras un método superior, propónlo.
